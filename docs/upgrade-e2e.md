# Luma 0.1.5 跨版本端到端验收

日期：2026-10-27。结果：**两轮通过**。本轮未修改正式程序代码或已发布安装包。

## 测试方式

| 场景 | 实际过程 | 结果 |
|---|---|---|
| 正式版覆盖升级 | 安装正式 0.1.4，读取并保存旧配置，结束旧进程，运行正式 0.1.5 安装包的更新模式 | 升级后自动重新打开正式 0.1.5 |
| 应用内自动更新 | 测试客户端检查 GitHub → 点击下载并更新 → 空缓存下载正式安装包 → 校验 → 退出旧进程 → 覆盖安装 → 自动重新打开 | 全链路通过，本次约 34.7 秒 |

正式 0.1.4 没有检查更新入口，因此第二轮使用隔离的旧版本诊断客户端：仅调整版本号与界面测试标识，更新实现与公开 v0.1.5 源码逐字节一致，已对照 GitHub 标签核验 SHA-256。目标为未经修改的公开 v0.1.5 安装包，最终程序文件与第一轮正式安装后的文件哈希一致。

初次 GitHub CLI 下载较慢，第一轮使用本地保存的发布包，并核对 GitHub 发布摘要。第二轮由应用实际联网下载，未填充更新缓存。

## 数据保留

测试使用独立的合成数据，日常数据先完整备份并在结束后恢复。覆盖内容包括：

- 3 个收藏单词及其释义、中文与英文笔记、多行文字、引号、重音字符、emoji、长笔记、收藏时间。
- 非默认取词方式、700 ms 停留、显示字段、悬浮球开关、自定义快捷键、服务地址、模型、目标语言。
- Windows DPAPI 加密的测试密钥，升级后仍可正常解密。
- 翻译历史、学习信息缓存与词源缓存。
- 第二轮增加的「关闭主窗口时完全退出」设置。

两轮升级前后，`settings.json`、`words.json`、`translations.json`、`details.json`、`etymologies.json` **全部逐字节一致**。重启后的界面正常显示 3 个词及笔记。

应用实际下载 96,644,448 字节，SHA-256 为 `00c49e982c66f142dff2e33fc24ad80de39842d20d17ec102f43ddbc9440267c`，与公开 Release 摘要一致。测试记录确认旧进程结束、新进程启动、安装器注册版本与程序版本变为 0.1.5。
