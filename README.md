# Luma 拾词

一个常驻 Windows 桌面的英语学习助手。按住 Alt 指向单词查词，用快捷键框选英文并翻译，把遇见的词留进本地单词本。

![Luma 界面](images/preview.png)

## 下载与安装

在 [Releases](https://github.com/No-thanks-237/luma-English-desktop/releases/latest) 下载：

- **Luma-0.1.5-Setup-x64.exe**：安装版，适合日常使用。默认安装到当前用户目录，提供开始菜单与卸载入口，桌面快捷方式可选。
- **Luma-0.1.5-Windows-x64.zip**：便携版，完整解压后打开 `Luma.exe`，不要只复制 exe。

支持 Windows 10/11 x64，自带 .NET 运行时。其他电脑如无法加载 OCR 原生库，可安装 [Microsoft Visual C++ x64 运行库](https://aka.ms/vs/17/release/vc_redist.x64.exe)。应用本体按当前用户安装。缺少 VC++ 时，运行库安装步骤需要联网与 Windows 管理员批准；本机已有兼容版本时可离线安装。安装包暂未代码签名。

## 使用

| 功能 | 默认操作 |
|---|---|
| 鼠标指向取词 | 按住 Alt，停留约 450 ms |
| 立即查鼠标处单词 | Ctrl+Alt+W |
| 框选句子翻译 | Ctrl+Alt+T |
| 暂停或恢复取词 | Ctrl+Alt+Space |
| 收起词卡、胶囊或框选 | Esc |
| 悬浮球 | 单击展开查词、翻译、单词本；拖动移动 |
| 贴边隐藏 | 拖到任一边缘，闲置后缩入边缘；鼠标靠近唤出 |

默认关闭主窗口后继续驻留托盘；「偏好设置 → 交互与显示 → 关闭主窗口时」可改为完全退出。主界面底部与悬浮球右键菜单均有「退出应用」。快捷键、停留时间、词卡内容、自动隐藏与动效均可在设置里调整。

## 功能

- UI Automation 取词优先，本地 Tesseract OCR 兜底。
- 770,611 个 ECDICT 离线词条，支持词形查询。
- 内置 611 条词根词缀记录，按明确例词关联 6,738 个英文单词；不随意按子串拆词。
- 维基词典官方 API 提供英语词源，保留来源与许可，缓存后可离线读取。
- DeepSeek 和 Chat Completions 格式的 OpenAI 兼容翻译接口，密钥在软件设置中填写。
- 本地单词本、学习笔记、CSV 导出、翻译历史与 Windows 英语语音朗读。
- 透明玻璃球、三键胶囊、四边吸附隐藏；珍珠白与冰蓝界面，可减少动态效果。

## 检查更新

打开「偏好设置 → 数据与关于」，点击「检查更新」。有新正式版时显示版本与更新说明，点击「下载并更新」即可。程序从本仓库 GitHub Releases 下载 Windows 安装包，验证大小与 SHA-256，保存数据后退出，等旧进程结束才启动安装。已有 OCR 运行库时自动安装并重新打开；缺少时进入交互安装以申请管理员批准。检查和下载都需要能访问 GitHub。

仅手动检查，不后台轮询、不接受预发布或降级；下载可取消。更新失败会提示或重新打开原应用。请先保存未保存的设置。便携版使用此功能会进入安装版流程。真实跨版本覆盖安装尚未完整实测，元数据、下载校验及等待器已分别验证。

## 数据与接口

用户数据位于 `%LOCALAPPDATA%\Luma`，卸载会保留。API 密钥通过当前 Windows 用户的 DPAPI 加密；首次使用需自行配置服务商与密钥。截图不上传，只有主动翻译或 AI 补充时才发送相应文本，在线词源只发送单词。

Google Cloud / Azure 官方翻译适配器尚未接入。OCR 与长词拼写校正可能出错，可手动修改原文。真实付费 AI 账户未做端到端调用验证，自动检查使用本地模拟接口。

## 构建

需要 .NET 8 SDK；首次还原需要网络。

```powershell
.\build.ps1
# 可选：安装 Inno Setup 6，生成 dist/ 下的安装包
.\build.ps1 -InstallerCompiler 'C:\Program Files (x86)\Inno Setup 6\ISCC.exe'
```

源码在 `src/`，发布程序在 `app/`；编译输出不加入 Git。安装脚本在 `installer/Luma.iss`。

```powershell
.\app\Luma.exe --self-test C:\path\to\isolated-test-output
.\app\Luma.exe --ui-preview --data-dir C:\path\to\isolated-preview-data --ui-audit C:\path\to\ui-audit-output
```

本版通过 23 项核心检查、75 项界面检查，包括标题栏原生命中、四边收回动画逐帧窗口与球心稳定、透明区域鼠标穿透。报告在 `test-results.json` 和 `ui-test-results.json`；另有 6 项独立进程关闭/重新打开/退出检查，见 `lifecycle-test-results.json`。部分多显示器 / DPI 验证属于几何测试，未穷尽硬件组合。

安装与卸载另通过 6 项检查，安装后的程序再次通过 23 项核心检查，原有用户数据保持不变；详见 `installer-test-results.json`。

更新等待器另通过 2 项交接与防篡改检查，见 `update-handoff-test-results.json`。
